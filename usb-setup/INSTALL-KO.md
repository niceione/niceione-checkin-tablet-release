# QR 미지원 태블릿 USB Device Owner 설치

NTP-10에서 Android Enterprise QR 등록 화면이 열리지 않을 때 사용하는 운영 절차입니다. 태블릿마다 PC에 USB로 한 번 연결해 Device Owner를 등록합니다. 등록이 끝난 뒤 앱 업데이트에는 PC나 사용자 승인이 필요하지 않습니다.

> **실기기 선행 검증 필수:** NTP-10은 출고 시기와 펌웨어에 따라 USB 드라이버, Device Owner 등록 허용 여부 및 KIS Agent 연동 동작이 달라질 수 있습니다. 전체 배포 전에 실제 NTP-10 한 대에서 아래의 `설치 후 필수 시험`을 모두 통과시킨 뒤 나머지 장비에 적용하십시오.

## 실기기 검증 현황

2026-09-29에 Android 11 기반 R10D 한 대에서 다음 항목을 확인했습니다.

- USB ADB 인식과 Device Owner 등록
- NiceIone v1.0.4 설치 및 기본 HOME 지정
- HOME·최근 앱 차단, 뒤로가기 시 앱 외부 이탈 방지
- 재부팅 후 자동 실행과 Lock Task 자동 복구
- 관리자 `앱 종료` 후 제조사 홈 화면 이동과 다른 앱·Android 설정 사용
- NiceIone 앱 재실행 시 전용 HOME 및 Lock Task 복구
- GitHub 최신 버전 확인과 1분 주기 반복 확인
- v1.0.2 → v1.0.3 → v1.0.4 사용자 승인 없는 APK 자동 설치 및 앱 자동 재실행
- 고객·관리자 화면 공통 상단 바의 현재 앱 버전 표시

KIS Agent가 아직 설치되지 않아 실제 카드 승인·승인 취소만 미검증 상태입니다.

## 준비물

- Windows PC와 데이터 통신이 가능한 USB 케이블
- 인터넷 연결
- KIS에서 제공한 Android Agent APK
- 이 프로젝트의 `tools/device-owner` 폴더

KIS Agent APK 파일명을 `kis-agent.apk`로 바꾸고 `Setup-NiceIone-Tablet.bat`와 같은 폴더에 둡니다. 태블릿에 `kr.co.kisvan.andagent`가 이미 설치되어 있으면 APK 파일은 없어도 됩니다.

## 태블릿에서 한 번만 설정

1. 필요한 거래자료와 설정을 백업합니다.
2. 안정적인 대량 작업을 위해 태블릿을 공장 초기화합니다.
3. Android 초기 설정에서 Google 계정 및 기타 계정을 추가하지 않고 설정을 완료합니다.
4. `설정 → 태블릿 정보 → 빌드 번호`를 7번 눌러 개발자 옵션을 활성화합니다.
5. `설정 → 시스템 → 개발자 옵션 → USB 디버깅`을 켭니다.
6. PC에 USB 케이블로 연결합니다.
7. 태블릿에 USB 디버깅 허용 창이 나오면 `이 컴퓨터에서 항상 허용`을 선택하고 허용합니다.

Device Owner 등록 전에는 계정이 없어야 하며 보조 사용자 또는 업무 프로필도 없어야 합니다. 이 조건을 만족하지 않으면 BAT가 중단됩니다.

## PC에서 실행

1. 한 번에 태블릿 한 대만 연결합니다.
2. `Setup-NiceIone-Tablet.bat`를 더블클릭합니다.
3. 완료 메시지가 나올 때까지 케이블을 분리하지 않습니다.
4. 완료 후 케이블을 분리하고 태블릿을 재부팅합니다.

BAT가 자동으로 수행하는 작업은 다음과 같습니다.

1. ADB가 없으면 Google 공식 Android Platform Tools를 준비합니다.
2. 연결 기기, Android 버전, 사용자, 계정, 기존 Device Owner를 확인합니다.
3. KIS Agent가 없으면 `kis-agent.apk`를 설치하고 패키지명을 검증합니다.
4. GitHub Release의 최신 NiceIone APK를 다운로드하고 SHA-256을 검증합니다.
5. 운영 APK를 설치하고 NiceIone 앱을 Device Owner로 등록합니다.
6. NiceIone을 기본 HOME으로 지정하고 Lock Task를 시작합니다.
7. Device Owner, 기본 HOME 및 Lock Task 상태를 최종 검증합니다.

## 설치 후 필수 시험

각 태블릿에서 다음 항목을 확인합니다.

- HOME, 최근 앱 및 뒤로가기로 고객이 앱을 이탈할 수 없다.
- 재부팅하면 NiceIone 앱이 자동 실행된다.
- KIS Agent가 연결되고 실카드 승인과 승인 취소가 정상이다.
- 앱 시작 및 1분 간격 자동 업데이트 확인이 동작한다.
- 지점코드, 9자리 기기 ID 및 객실코드가 해당 객실과 일치한다.

시험 기기 한 대에서 위 항목을 모두 확인한 후 나머지 기기를 작업합니다.

## 관리자 앱 종료와 복구

관리자 PIN으로 관리자 설정에 들어가 우측 상단 `앱 종료`를 누릅니다. 확인 후 다음 작업이 수행됩니다.

- Lock Task와 기본 HOME 고정이 일시 해제됩니다.
- 제조사 기본 홈 화면으로 이동합니다.
- 홈 화면에서 다른 앱을 실행하거나 Android 설정을 사용할 수 있습니다.
- Device Owner 자체는 유지되므로 공장 초기화할 필요가 없습니다.

유지보수를 마친 뒤 NiceIone 앱을 다시 실행하거나 태블릿을 재부팅하면 HOME·뒤로가기 제한과 자동 실행 정책이 복구됩니다.

## 실패할 때 확인

- `unauthorized`: 태블릿에서 USB 디버깅을 허용합니다.
- 계정 존재: 설정에서 Google 및 기타 계정을 모두 제거합니다.
- 사용자가 2명 이상: 보조 사용자와 업무 프로필을 제거합니다.
- 다른 Device Owner 존재: 기존 MDM 관리자에게 확인하거나 공장 초기화합니다.
- Device Owner 등록 거부: 공장 초기화 후 계정을 추가하지 않은 상태로 다시 시도합니다.
- KIS Agent 없음: 올바른 KIS Agent APK를 `kis-agent.apk` 이름으로 BAT 옆에 둡니다.

운영 서명 앱은 ADB 명령으로 Device Owner를 제거할 수 없습니다. 완전히 해제하려면 공장 초기화가 필요합니다. 일반 유지보수에는 관리자 `앱 종료` 기능을 사용합니다.
