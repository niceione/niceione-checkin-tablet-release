# NTP-10 전체 설치·운영 가이드

이 문서는 QR 프로비저닝을 사용할 수 없는 NTP-10을 Windows PC와 USB 케이블로 설정하는 전체 절차입니다. 공장 초기화부터 Device Owner 등록, 기기별 관리자 설정, 유지보수, KIS Agent 후설치, 자동 업데이트 및 장애 대응까지 설명합니다.

- 공식 버전: `v1.0.0`
- Android 내부 `versionCode`: `1`
- 앱 패키지: `kr.co.niceione.checkintablet`
- Device Owner 관리자: `kr.co.niceione.checkintablet.NiceIoneDeviceAdminReceiver`
- KIS Agent 패키지: `kr.co.kisvan.andagent`
- 공식 배포: <https://github.com/niceione/niceione-checkin-tablet-release/releases/latest>
- USB 설치 ZIP: <https://github.com/niceione/niceione-checkin-tablet-release/releases/download/v1.0.0/niceione-tablet-usb-setup-v1.0.0.zip>

공식 첫 배포 버전은 `versionName=1.0.0`, `versionCode=1`입니다. 사용자 화면과 APK 파일명에는 `v1.0.0`만 표시됩니다. 다음 공식 버전은 `versionName=1.0.1`, `versionCode=2` 이상으로 게시합니다.

> **한 대 선행 검증 필수:** NTP-10은 출고 시기와 펌웨어에 따라 USB 드라이버, Device Owner 허용 여부 및 KIS Agent 동작이 다를 수 있습니다. 실제 장비 한 대에서 이 문서의 시험을 모두 통과한 뒤 나머지 장비에 적용하십시오.

## 1. 이번에 적용한 기능과 수정 내용

### 1.1 Device Owner와 키오스크 잠금

- NiceIone 앱을 Android Device Owner로 등록합니다.
- NiceIone을 기본 HOME 앱으로 고정합니다.
- Android Lock Task 모드를 사용해 고객 화면에서 HOME과 최근 앱 버튼을 차단합니다.
- 뒤로가기는 앱 밖으로 나가지 않고 NiceIone 내부의 이전 화면 또는 첫 화면으로만 이동합니다.
- KIS Agent 패키지는 결제 화면 전환을 위해 Lock Task 허용 목록에 포함됩니다.
- Device Owner는 일반 앱 관리자 권한보다 강한 전용 단말 권한입니다. 완전히 제거하려면 공장 초기화가 필요합니다.

### 1.2 재부팅 후 자동 실행

- 재부팅 후 Android의 `BOOT_COMPLETED` 이벤트를 받아 NiceIone HOME 정책과 Lock Task를 복구합니다.
- 제조사 부팅 서비스가 모두 시작된 뒤 앱이 실행되므로 NTP-10에서는 전원 부팅 후 약 30~50초 동안 홈 화면이 잠시 보일 수 있습니다.
- 부팅이 완료되면 NiceIone이 자동 실행되고 다시 `LOCKED` 상태가 됩니다.

### 1.3 관리자 `앱 종료` 유지보수 모드

- 관리자 설정 우측 상단에 `앱 종료` 버튼을 추가했습니다.
- 확인 후 Lock Task를 해제하고 NTP-10의 제조사 기본 홈 화면으로 이동합니다.
- 특정 런처 이름을 고정하지 않고 각 태블릿의 HOME 후보를 조회해 제조사 런처를 선택합니다.
- 유지보수 중에는 다른 앱, Android 설정, 파일 관리자 등을 사용할 수 있습니다.
- Device Owner 자체는 유지되므로 다시 공장 초기화할 필요가 없습니다.
- NiceIone을 다시 실행하거나 태블릿을 재부팅하면 NiceIone 기본 HOME과 Lock Task가 자동 복구됩니다.

관리자 화면의 두 버튼은 동작이 다릅니다.

- `닫기`: 고객 화면으로 돌아가며 키오스크 잠금을 유지합니다.
- `앱 종료`: 키오스크 잠금을 일시 해제하고 일반 홈 화면으로 이동합니다.

### 1.4 GitHub 자동 업데이트

- 앱 시작 시 한 번, 실행 중에는 1분마다 GitHub Release의 `update.json`을 확인합니다.
- 다음 조건을 모두 만족할 때만 새 APK를 설치합니다.
  - NiceIone 첫 화면이 실행 중이다.
  - 마지막 화면 터치 후 1분 이상 지났다.
  - 고객 체크인, 본인인증 또는 결제가 진행 중이지 않다.
  - 관리자 화면이나 확인창이 열려 있지 않다.
  - 복구해야 할 미완료 결제가 없다.
- APK의 HTTPS 주소, SHA-256, 패키지명, `versionCode`, `versionName` 및 서명을 검증합니다.
- 검증된 APK만 Device Owner 권한의 Package Installer로 무인 설치합니다.
- 설치 허용 버튼이나 `출처를 알 수 없는 앱` 승인 화면이 나타나지 않습니다.
- 설치가 끝나면 NiceIone이 자동으로 다시 실행됩니다.
- 관리자 `앱 종료` 상태에서는 NiceIone이 실행되지 않으므로 업데이트도 확인하지 않습니다. 앱을 다시 열거나 재부팅하면 업데이트 확인이 재개됩니다.

### 1.5 상단 상태 바

고객 화면, 관리자 화면 및 앱 내부 팝업의 공통 상단 바에 다음 항목을 표시합니다.

- 현재 시각
- 현재 앱 버전: `v1.0.0` 형식으로만 표시
- 인터넷 연결 상태
- 배터리 잔량 및 충전 상태

### 1.6 KIS 승인·취소 연결

- KIS Agent의 Activity 결과 방식으로 카드 승인을 요청합니다.
- 승인 거래와 승인 취소 거래를 로컬 DB에 별도로 기록합니다.
- 승인 응답이 불확실하거나 승인금액이 다르면 새 결제를 차단해 중복 승인을 방지합니다.
- 관리자 `결제 거래내역`에서 원거래를 선택해 승인 취소를 진행할 수 있습니다.
- 현재 연결된 실기기에는 KIS Agent가 설치되지 않아 실카드 승인과 승인 취소만 미검증 상태입니다.

- 유지보수 상태에서 Android 설정 실행 및 HOME 버튼 사용

## 3. 준비물

- Windows 10 또는 Windows 11 PC
- 인터넷 연결
- 충전 전용이 아닌 데이터 통신 USB 케이블
- 공장 초기화할 NTP-10
- `niceione-tablet-usb-setup-v1.0.0.zip`
- KIS Agent를 함께 설치하려면 KIS에서 받은 Android Agent APK

ZIP을 내려받아 짧은 영문 경로에 압축을 풉니다. 예시는 다음과 같습니다.

```text
C:\NiceIone-Setup\
  Setup-NiceIone-Tablet.bat
  Setup-ProductionDeviceOwner.ps1
  KIS_AGENT_APK_HERE.txt
  INSTALL-KO.md
```

KIS Agent를 같이 설치한다면 APK 파일명을 `kis-agent.apk`로 변경해 같은 폴더에 놓습니다.

```text
C:\NiceIone-Setup\kis-agent.apk
```

## 4. 태블릿 공장 초기화와 초기 설정

Device Owner 최초 등록은 계정과 보조 사용자가 없는 초기 상태에서만 가능합니다.

1. 기존 거래자료, 설정 및 필요한 파일을 백업합니다.
2. NTP-10을 공장 초기화합니다.
3. Android 초기 설정에서 Wi-Fi에 연결합니다.
4. Google 계정과 기타 계정은 추가하지 않습니다.
5. 화면 잠금 PIN, 보조 사용자 및 업무 프로필도 만들지 않습니다.
6. 초기 설정을 완료해 일반 홈 화면까지 들어갑니다.
7. `설정 → 태블릿 정보 → 빌드 번호`를 7번 연속 누릅니다.
8. `개발자 옵션이 활성화되었습니다` 안내를 확인합니다.
9. `설정 → 시스템 → 개발자 옵션 → USB 디버깅`을 켭니다.

메뉴 이름은 펌웨어에 따라 `태블릿 정보`, `기기 정보`, `시스템`처럼 조금 다를 수 있습니다.

## 5. PC 연결과 USB 디버깅 허용

1. 한 번에 NTP-10 한 대만 PC에 연결합니다.
2. 태블릿 USB 사용 방식이 나오면 `파일 전송` 또는 `MTP`를 선택합니다.
3. 태블릿의 `USB 디버깅을 허용하시겠습니까?` 창에서 `이 컴퓨터에서 항상 허용`을 선택합니다.
4. `허용`을 누릅니다.
5. 허용창이 나오지 않으면 USB 디버깅을 껐다 켜거나 데이터 케이블과 USB 포트를 변경합니다.

## 6. Device Owner 자동 설치

### 6.1 KIS Agent를 함께 설치하는 경우

`kis-agent.apk`가 BAT와 같은 폴더에 있는지 확인한 뒤 `Setup-NiceIone-Tablet.bat`를 더블클릭합니다.

### 6.2 KIS Agent를 나중에 설치하는 경우

설치 폴더의 빈 공간을 Shift+우클릭하고 `터미널에서 열기`를 선택한 뒤 다음 명령을 실행합니다.

```powershell
.\Setup-NiceIone-Tablet.bat -SkipKisAgent
```

이 경우 Device Owner와 NiceIone 키오스크 기능은 정상 적용되지만 실카드 결제는 KIS Agent 설치 전까지 동작하지 않습니다.

### 6.3 BAT가 자동으로 수행하는 작업

1. PC에 ADB가 없으면 Google 공식 Android Platform Tools를 준비합니다.
2. USB 디버깅이 허용된 태블릿이 정확히 한 대인지 확인합니다.
3. 모델명, Android 버전 및 SDK 버전을 확인합니다.
4. 기존 Device Owner, Android 사용자 수 및 계정 존재 여부를 확인합니다.
5. KIS Agent가 이미 설치되어 있으면 재사용합니다.
6. 필요한 경우 `kis-agent.apk`를 `adb install -r -g` 방식으로 설치합니다.
7. GitHub 최신 Release의 `update.json`과 APK를 다운로드합니다.
8. APK SHA-256이 `update.json`과 일치하는지 확인합니다.
9. NiceIone 운영 APK를 설치합니다.
10. NiceIone을 Device Owner로 등록합니다.
11. NiceIone을 기본 HOME으로 지정하고 Lock Task를 시작합니다.
12. Device Owner, HOME 및 Lock Task 상태를 다시 읽어 최종 검증합니다.

정상 완료 시 마지막에 다음 항목이 `적용`으로 표시됩니다.

```text
- HOME/최근 앱/뒤로가기 제한: 적용
- 재부팅 후 자동 실행: 적용
- 앱 자체 자동 업데이트: 적용
- 관리자 앱 종료: 관리자 설정 우측 상단 '앱 종료'
```

오류가 표시되면 케이블을 분리하거나 공장 초기화를 반복하지 말고 이 문서의 `장애 대응`을 먼저 확인합니다.

## 7. 앱 최초 관리자 설정

설치 직후 기기 설정이 없으면 관리자 화면이 자동으로 열립니다.

1. 우측 `스테이원 기기 등록` 영역에서 운영 또는 스테이지 API 서버를 선택합니다.
2. 지점코드를 입력합니다.
3. 해당 태블릿에 사용할 9자리 기기 ID를 입력합니다.
4. `스테이원 기기 등록`을 누릅니다.
5. 등록 성공을 확인합니다.
6. 좌측 `태블릿 설정`에서 객실코드를 입력합니다.
7. 기본 관리자 PIN `000000`을 현장 운영 PIN으로 변경합니다.
8. 화면 방향과 결제 모드를 선택합니다.
9. `설정 저장`을 누릅니다.
10. `닫기`를 눌러 고객 첫 화면으로 이동합니다.

각 태블릿은 다음 값이 다른 태블릿과 겹치지 않아야 합니다.

- 9자리 기기 ID
- 객실코드
- 실제 설치 객실

운영 배포 전에는 `가상 결제 사용`과 `가상 본인인증 통과`를 끕니다. KIS Agent가 준비되지 않은 동안에만 `KIS 테스트 결제` 또는 개발용 가상 결제를 사용합니다.

## 8. 관리자 화면 진입과 유지보수

### 8.1 관리자 화면 진입

1. 고객 첫 화면 좌측 상단 `나이스아이원 · CHECK-IN`을 3초 안에 5번 누릅니다.
2. 관리자 PIN을 입력합니다.
3. 관리자 설정 화면이 열립니다.

PIN을 잊으면 고객 화면에서 임의로 해제할 수 없습니다. 운영 전에 PIN을 안전한 관리 문서에 기록합니다.

### 8.2 일반 설정 후 고객 화면으로 돌아가기

우측 상단 `닫기`를 누릅니다. 키오스크 잠금은 계속 유지됩니다.

### 8.3 다른 앱이나 Android 설정 사용하기

1. 우측 상단 `앱 종료`를 누릅니다.
2. 확인창의 `앱 종료`를 다시 누릅니다.
3. 제조사 홈 화면으로 이동합니다.
4. 필요한 앱 또는 Android 설정을 사용합니다.

유지보수가 끝나면 NiceIone 아이콘을 실행합니다. 아이콘을 찾기 어렵다면 태블릿을 재부팅해도 됩니다. 재부팅 복구에는 약 30~50초가 걸릴 수 있습니다.

## 9. KIS Agent를 나중에 설치하는 방법

기존 Device Owner와 기기별 설정을 유지한 채 Agent만 추가할 수 있습니다.

1. 관리자 `앱 종료`로 Android 설정에 접근합니다.
2. 개발자 옵션과 USB 디버깅이 켜져 있는지 확인합니다.
3. KIS에서 받은 APK 이름을 `kis-agent.apk`로 변경합니다.
4. APK를 `Setup-NiceIone-Tablet.bat`와 같은 폴더에 놓습니다.
5. 태블릿을 PC에 연결하고 USB 디버깅을 허용합니다.
6. `Setup-NiceIone-Tablet.bat`를 다시 실행합니다.
7. BAT는 기존 Device Owner를 확인하고 유지한 채 KIS Agent와 최신 NiceIone을 설치합니다.
8. 완료 후 NiceIone을 다시 실행하거나 재부팅합니다.

설치 후 다음 시험을 반드시 진행합니다.

1. KIS Agent 가맹점 정보와 CAT ID를 설정합니다.
2. 최소 금액으로 실카드 승인을 진행합니다.
3. NiceIone 관리자 `결제 거래내역`에서 승인번호와 금액을 확인합니다.
4. 같은 거래를 선택해 `KIS 승인 취소`를 실행합니다.
5. 카드 단말 또는 KIS 거래내역에서 취소 완료를 확인합니다.

## 10. 자동 업데이트 운영 방법

### 10.1 태블릿에서 업데이트되는 조건

1. NiceIone이 실행 중이어야 합니다.
2. 고객 첫 화면이어야 합니다.
3. 마지막 터치 후 1분 이상 지나야 합니다.
4. 결제, 본인인증, 관리자 화면, 팝업 및 미완료 거래가 없어야 합니다.
5. 인터넷에 연결되어야 합니다.

조건을 만족하지 않으면 업데이트 파일을 준비한 뒤 안전해질 때까지 설치만 연기합니다.

### 10.2 다음 버전 게시 규칙

공식 `v1.0.0`의 내부 `versionCode`는 1입니다. 다음 버전은 반드시 더 큰 내부 코드를 사용합니다.

```powershell
.\tools\release\Build-GitHubRelease.ps1 `
  -VersionCode 2 `
  -VersionName "1.0.1" `
  -Repository "niceione/niceione-checkin-tablet-release" `
  -ReleaseNotes "변경 내용" `
  -Publish
```

- 기존 릴리스 APK를 같은 이름으로 교체하지 않습니다.
- 새 버전마다 새 Git 태그와 더 큰 `versionCode`를 사용합니다.
- Android는 작은 `versionCode`로 자동 복귀하지 않습니다.
- 잘못된 버전을 게시했다면 더 큰 `versionCode`의 수정 버전을 새로 게시합니다.
- 게시 후 시험 장비 한 대에서 자동 설치와 앱 재실행을 확인한 뒤 전체 장비에 적용합니다.

## 11. 여러 대에 적용하는 방법

- 등록 대수 제한은 없습니다.
- USB Device Owner 등록은 안전을 위해 한 번에 한 대씩 진행합니다.
- 같은 USB ZIP과 BAT를 모든 장비에 재사용할 수 있습니다.
- APK와 스크립트를 장비마다 복사할 필요는 없습니다.
- 각 장비의 기기 ID와 객실코드는 고유해야 합니다.
- 먼저 한 대를 완전히 검증한 뒤 동일 절차로 다음 장비를 반복합니다.

권장 기록 항목은 다음과 같습니다.

| 항목 | 기록 예시 |
|---|---|
| 객실 | 301호 |
| ADB 시리얼 | 장치별 시리얼 |
| 9자리 기기 ID | StayOne 등록값 |
| 지점코드 | 운영 지점 |
| 객실코드 | StayOne 객실코드 |
| 앱 버전 | v1.0.0 |
| KIS 승인/취소 | 통과 또는 미검증 |
| 설치일 | YYYY-MM-DD |

## 12. 설치 후 필수 점검표

- [ ] 상단 바에 `v1.0.0`만 표시된다.
- [ ] HOME 버튼으로 고객이 앱 밖으로 나갈 수 없다.
- [ ] 최근 앱 버튼으로 다른 앱을 선택할 수 없다.
- [ ] 뒤로가기로 NiceIone 외부로 이탈하지 않는다.
- [ ] 재부팅 후 약 30~50초 이내에 NiceIone이 자동 실행된다.
- [ ] 관리자 `닫기`는 고객 화면으로 돌아간다.
- [ ] 관리자 `앱 종료`는 제조사 홈 화면으로 이동한다.
- [ ] 유지보수 홈에서 다른 앱과 Android 설정을 사용할 수 있다.
- [ ] NiceIone 재실행 또는 재부팅 후 키오스크가 복구된다.
- [ ] 지점코드, 기기 ID와 객실코드가 실제 객실과 일치한다.
- [ ] 인터넷 연결 상태가 상단 바에 정상 표시된다.
- [ ] KIS Agent 설치 후 실카드 승인과 승인 취소가 정상이다.
- [ ] 다음 시험 버전으로 1분 idle 자동 업데이트가 정상이다.

## 13. 장애 대응

### ADB에서 장치가 보이지 않음

- 데이터 통신 USB 케이블인지 확인합니다.
- 다른 USB 포트를 사용합니다.
- 태블릿 USB 모드를 `파일 전송`으로 변경합니다.
- USB 디버깅을 껐다가 다시 켭니다.
- Windows 장치 관리자에서 Android 또는 알 수 없는 USB 장치 오류를 확인합니다.

### `unauthorized`

태블릿 화면을 켜고 USB 디버깅 허용창에서 `이 컴퓨터에서 항상 허용`과 `허용`을 누릅니다. 창이 나오지 않으면 개발자 옵션의 `USB 디버깅 승인 취소`를 실행한 뒤 다시 연결합니다.

### 연결 장치가 2대 이상이라고 표시됨

에뮬레이터와 다른 Android 장치를 종료하거나 분리하고 NTP-10 한 대만 남깁니다.

### 계정이 있어 Device Owner 등록 실패

Google 계정, 기타 계정, 보조 사용자 또는 업무 프로필을 모두 제거합니다. 제거가 확실하지 않으면 다시 공장 초기화하고 계정을 추가하지 않습니다.

### 다른 Device Owner가 존재함

기존 MDM 또는 Device Owner를 일반 ADB 명령으로 덮어쓸 수 없습니다. 기존 관리 시스템에서 해제하거나 공장 초기화해야 합니다.

### KIS Agent가 없다고 중단됨

- 함께 설치: 올바른 Agent APK를 `kis-agent.apk`로 BAT 옆에 둡니다.
- 나중에 설치: 터미널에서 `.\Setup-NiceIone-Tablet.bat -SkipKisAgent`를 실행합니다.

### 재부팅 직후 홈 화면이 보임

NTP-10에서 Android 부팅 완료 이벤트가 전달될 때까지 약 30~50초가 걸릴 수 있습니다. 잠시 기다린 뒤 NiceIone이 실행되고 HOME이 잠기는지 확인합니다. 계속 홈 화면이면 NiceIone을 직접 실행한 뒤 다시 재부팅합니다.

### 자동 업데이트가 바로 설치되지 않음

- 고객 또는 관리자 화면을 조작 중이면 설치하지 않습니다.
- 관리자 `앱 종료` 상태에서는 앱이 실행되지 않아 확인하지 않습니다.
- 고객 첫 화면으로 돌아와 팝업을 닫고 1분 이상 터치하지 않습니다.
- 상단 바의 인터넷 연결 상태를 확인합니다.
- `내부 저장소/Documents/NiceIoneCheckIn/logs`의 최신 로그에서 `AutoUpdate` 항목을 확인합니다.

### Device Owner를 완전히 제거하고 싶음

운영 서명 앱의 Device Owner는 일반 ADB 명령으로 제거할 수 없습니다. 필요한 자료를 백업한 뒤 공장 초기화합니다. 단순 유지보수에는 Device Owner를 제거하지 말고 관리자 `앱 종료`를 사용합니다.

## 14. QR 프로비저닝 참고

현재 확인한 NTP-10은 QR 프로비저닝 화면을 사용할 수 없어 USB BAT 방식을 기본으로 사용합니다. QR 프로비저닝을 지원하는 다른 Android 기기에서는 Release의 QR을 사용할 수 있습니다.

QR에는 다음 정보만 포함됩니다.

- 공개 APK 다운로드 주소
- Device Owner 관리자 컴포넌트
- APK SHA-256 체크섬
- 기존 Android 시스템 앱 유지 설정

Wi-Fi 비밀번호, GitHub 계정, 토큰, 지점코드, 객실코드, 기기 ID, 관리자 PIN 및 고객정보는 포함되지 않습니다.

## 15. 배포 파일 설명

| 파일 | 용도 |
|---|---|
| `niceione-checkin-1.0.0-release.apk` | 운영 서명 APK |
| `update.json` | 태블릿이 1분마다 확인하는 최신 버전 정보 |
| `niceione-tablet-usb-setup-v1.0.0.zip` | QR 미지원 NTP-10 USB 설치 묶음 |
| `niceione-device-owner-qr.png` | QR 지원 기기용 Device Owner QR |
| `niceione-device-owner.json` | QR 원본 프로비저닝 데이터 |

운영 릴리스의 APK, `update.json` 및 QR은 서로의 버전과 SHA-256이 연결되어 있습니다. 릴리스 자산 일부만 임의로 교체하거나 삭제하지 않습니다.
